# 🎂 Pastelería Mágica

¡Bienvenido a **Pastelería Mágica**!  
Un proyecto moderno construido con **React 19** y **Vite 7** para crear experiencias web rápidas, interactivas y deliciosas.

## 🚀 Características

- ⚡️ Renderizado ultrarrápido con Vite
- 🔥 Recarga en caliente (HMR) para desarrollo ágil
- 🎨 Estilos modernos y responsivos
- 🧹 Linting automático con ESLint y reglas para React
- 🛠️ Estructura lista para escalar y personalizar
